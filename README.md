# Wiki Pokémon FireRed — Guia da versão modificada

Wiki em português para a versão modificada de Pokémon FireRed. O site é uma página única, responsiva e pode ser aberto localmente, inclusive sem internet.

## Abrir

Abra `index.html` em qualquer navegador moderno. Use a barra de pesquisa para filtrar os guias. Pressione `/` para focar a pesquisa e `Esc` para limpar e sair do campo.

## Guias incluídos

- EXP ALL: ativação, opção padrão e distribuição de experiência.
- Pokémon seguidor: espécies aceitas e ajuste no menu de opções.
- Painel de Desafios: categorias, navegação e roteiro para 100%.
- Encontros selvagens dos Pokémon exclusivos da LeafGreen.
- Evoluções sem troca e evoluções com item no nível 40.
- Itens, missões secundárias, trocas, treinadores, exploração e lendários.
- Pesquisadora da Ilha Um e eventos de Deoxys/Mew.

## Arquivos

- `index.html` — site completo, incluindo estilo e busca.
- `README.md` — este guia.

A ROM e os arquivos de save não fazem parte deste repositório. O arquivo `.gba` permanece no computador do jogador.
